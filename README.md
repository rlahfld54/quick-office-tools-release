# 💡 왜 만들었나요?

회사에서 일하다 보면 이런 일이 은근히 많습니다.

```text
파일 이름 수십 개 바꾸기
PDF 여러 개 처리하기
파일 정리하기
같은 작업 계속 반복하기
```

하나하나는 어려운 일이 아니지만  
반복하다 보면 생각보다 많은 시간이 필요합니다.

Quick Office Tools는

> **“이거 그냥 버튼 한 번으로 하면 안 되나?”**

라는 생각에서 시작했습니다.

거대한 업무 시스템보다는  
**매일 조금씩 시간을 잡아먹는 작은 반복 업무를 줄이는 것**이 목표입니다.

# ✨ 제공 기능

## 📝 파일명 일괄 변경

여러 파일의 이름을 하나씩 수정하지 않고  
규칙을 지정하여 한 번에 변경할 수 있습니다.

- 여러 파일 선택
- 순번 자동 생성
- 파일명 규칙 적용
- 변경 결과 미리보기
- 확장자 보호
- 중복 파일명 검사

---

## 🖨️ PDF 일괄 인쇄

여러 PDF 파일을 하나씩 열고 인쇄할 필요 없이  
한 화면에서 파일과 인쇄 설정을 확인한 뒤 처리할 수 있습니다.

- 여러 PDF 추가
- 출력 순서 변경
- 프린터 선택
- 인쇄 방향 설정
- 페이지 맞춤
- 여러 파일 연속 처리

---

## 📁 파일 정리

반복적인 파일 정리 작업을 보다 간단하게 처리할 수 있도록  
파일 관리 기능을 제공합니다.

---

# 🚧 계속 추가하고 있습니다

Quick Office Tools는 완성된 기능 목록을 고정해 두는 프로그램이 아닙니다.

실제로 사무 업무를 하면서

> “이거 너무 귀찮다.”

싶은 작업을 발견하면 하나씩 도구로 추가하고 있습니다.

앞으로도 **Excel · PDF · 파일 관리 · 반복 사무 업무**를 중심으로 기능을 확장할 예정입니다.

---

# 🔒 파일 처리 방식

Quick Office Tools는 데스크톱 프로그램입니다.

가능한 작업은 사용자의 PC에서 처리하여  
개인 파일을 다루는 사무도구를 보다 편하게 사용할 수 있도록 개발하고 있습니다.

# 📮 더 복잡한 메일 업무가 필요하다면?

거래처별 Excel/PDF 자료를 만들고  
각 담당자에게 첨부해서 메일을 보내는 업무를 반복하고 있다면

**메일딸깍** 프로젝트도 확인해 보세요.

### 📮 메일딸깍

```text
Excel 데이터
    ↓
검증
    ↓
거래처별 마감자료
    ↓
첨부 확인
    ↓
메일 발송
```

반복되는 매출 마감 및 거래처 메일 업무를  
하나의 흐름으로 처리하기 위한 데스크톱 프로그램입니다.
